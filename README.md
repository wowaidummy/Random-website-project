hello reader,
this is quite a simple project I have made using javascript, css and html
I have followed the tutorial for the creation of the website, and made changes to the code(mainly css) for a much better ui and styling. 
In this project you will see a webpage in which I first fetch a photo from NASA's api key, then the photo's date, explanation, title etc to display on the page. 
you can also refresh the page by the refresh button on the bottom which will fetch a new photo (or the same photo sometimes).

to test this simply go to: https://nasaarticles.vercel.app/
if you want to run locally, just download this repo and run "npm run dev" in the terminal of this folder and head to local host
